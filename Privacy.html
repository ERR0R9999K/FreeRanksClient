Privacy Policy

FreeRanksClient — Your Security and Transparency

Completely Safe

Your Security is Our Priority

FreeRanksClient (FRC) is a client created with one single purpose: to provide Bloxd.io players with access to exclusive ranks completely free. We guarantee that our client:

  • Is not a virus — the client code is verified and safe
  • Is not a cheat — we do not violate game rules
  • Does not mine cryptocurrency — the client doesn't use your resources
  • Does not steal data — we don't collect passwords or personal information
  • Does not save your accounts — the client has no access to your profile

Code Obfuscation

The FreeRanksClient code is obfuscated (protected from reading). This is done exclusively to protect intellectual property from theft and unauthorized copying.

Important to understand: Obfuscation is a standard code protection practice that does not hide malicious functions, but only makes the code harder to read to protect copyright. The client does not contain viruses, miners, or spyware.

Technology Stack

FreeRanksClient is built on a modern and reliable technology stack. The core logic is written in JavaScript, which dynamically modifies the HTML and interacts with the game engine.

Starting from version 4.0.0, the client works directly with the Noa game engine, which is based on Babylon.js (version 8.13.0). This integration allows us to implement advanced visual features:

JavaScript Core logic & HTML modifications
Noa Engine Game engine integration (since v4.0.0)
Babylon.js 9.19.0 3D rendering & visual effects
What does this give to players? Thanks to the modification of the Noa engine, players can see ranks in name tags (since version 4.4.1) and capes (since version 4.0.0). Without this technology, these visual elements would simply be invisible. Modifying Noa is a critical part of the client that makes the gaming experience unique.

Important: The client does not modify the game files on disk. All changes are made in the browser memory and are reset after the session ends.

What Data Do We Store?

The client stores only the information that you voluntarily provide when submitting a rank request:

Player nickname
Nickname color
Player rank
Player skin (head only)
Cape
Important: The skin is saved exclusively to display the player's head in the client's user list. This is the only information that the client stores from your account.

How Do We Get Data?

All data stored by FreeRanksClient is transferred exclusively through Discord when submitting a rank request. You voluntarily send:

  • Screenshot of the Bloxd.io main page with your nickname visible
  • Your nickname (as text)
  • Desired rank
  • Nickname color

The client has no access to your account, password, or any other data that you haven't provided yourself.

Your Rights

  • You can request deletion of all your data at any time
  • You have full access to the information we store about you
  • You can stop using the client at any time

New Personalization System (v4.6.0+)

Starting from version 4.6.0, FreeRanksClient features a convenient registration form directly on the website. The process of getting a personalized client has never been easier or faster!

How does it work?
1. Click "Download" on the website — the registration window will open.
2. Fill out the form: Enter your in-game nickname, select your desired rank (you can pick multiple!), nickname color, and your preferred cape.
3. Click "Next" — the client is instantly generated specifically for you!
4. Download the ready script and install it in Tampermonkey.

What happens to your data?

When you fill out the form, your data is written directly into the code of the downloaded client — this is your personal file that already contains all your chosen settings. You can manually change this data inside the client, but it will not affect how your rank appears to other players.

How does rank display work?

It's important to understand how the rank display system works:

Via Discord ✅ Everyone sees it
Via the website form ✅ Everyone sees it
Manual changes in the code ❌ Only you see it
Why is that?
The client uses a central database (DB) that stores all confirmed player data. When you launch the client, it accesses this DB and loads information about all players. If your nickname is not in the DB — the client only loads local data (the one written in your file), and only you will see your rank.

The main DB takes priority! This means:

  • Ranks, nickname colors, and capes from the DB are visible to all players.
  • Ranks that you manually wrote in the client code are not visible to other players.

How to update your data in the DB?

If you've registered but want to change your data (for example, change your rank or color):

  1. Fill out the registration form again with your new data.
  2. The developer will receive a notification and replace your old data in the DB with the new one.
  3. After the DB update, all players will see your new settings.
Important: Manually changing data in the client code will not update the information in the DB. Your changes will only be visible to you.

How to check if you're in the DB?

After installing the client, pay attention to the message in the top-right corner of the screen:

You're in the DB

The local player load message does NOT appear

You're NOT in the DB

You'll see the message "Loading local player..."

If you see the local player loading message — your rank is only visible to you, until the developer adds you to the DB.

Getting ranks via Discord

The website registration system is a convenient additional way to get a personalized client. You can still contact the developer via Discord to get a rank. Both methods lead to the same result — your nickname will be added to the DB, and other players will see your rank.

Your privacy is our priority

Data from the registration form is used exclusively for:

  • Generating your personal client (with your data embedded).
  • Adding you to the DB (after verification by the developer).
We do not collect, store, or share your personal data with third parties. The entire process is completely transparent and secure.

FreeRanksClient is a 100% safe tool for getting free ranks. We value your trust and guarantee full transparency.
